In this exercise, we are following the VLSM method.

LAN 2:

Network ID: 192.168.5.0/25
PC1 IP Address: 192.168.5.1/25 (Subnet Mask: 255.255.255.128)
Router Interface (g0/1): 192.168.5.126/25 (Subnet Mask: 255.255.255.128)
Configuration:
For the PC, we should manually add the configuration.

Router Configuration:
bash
Copy
Edit
en  
config t  
interface g0/1  
ip address 192.168.5.126 255.255.255.128  
no shutdown  
exit
